# Project Name:  Interactive Web App for Cyber Security Awareness in Education
## Description 
Project Summary: I will design, research and develop an interactive web app that teaches children aged twelve to sixteen the fundamentals of cyber security, drawing on research into similar platforms and my own experience working with children. The app will replace traditional reading-based learning with interactive quizzes, learning cards, gamification and a database that logs quiz results and scores. My aim is to make learning enjoyable while helping young people understand why cyber security matters for their futures.

Scope: 
-  Front end built with HTML and CSS, responsive so it works on desktop and mobile browsers
-  JavaScript for the interactive portions of the project
- Learning content covering core cyber security fundamentals, such as password safety, phishing, social media privacy, malware and safe browsing
- A SQL database (for example MySQL) storing users, quiz questions, quiz results and scores, accessed through PHP
- A user registration and login system built in PHP, with hashed passwords and session handling
- Gamification elements such as points, badges and progress tracking, with data stored in the database
